# SOC Home Lab Using Wazuh SIEM

## Project Overview
This project focuses on learning Security Operations Center (SOC) fundamentals using Wazuh SIEM.

## Objectives
- Understand SIEM and security monitoring.
- Learn endpoint log collection and analysis.
- Investigate security alerts.
- Document incident investigation steps.

## Planned Environment
- Wazuh SIEM
- Linux virtual machine
- Wazuh agent
- VMware virtualization

## Project Status
In Progress — lab deployment, testing, and alert investigation are pending.
